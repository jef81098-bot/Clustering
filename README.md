# NHANES Adolescent Diet Clustering

## 專案簡介

本專案使用美國國家健康與營養調查（National Health and Nutrition Examination Survey, NHANES）資料，針對青少年飲食型態進行資料整理、探索性分析及分群分析。

透過統計分析與非監督式學習方法，探索青少年飲食型態的分布與潛在群體特徵，作為後續公共衛生及營養流行病學研究的參考。

## 專案內容

本專案主要使用 R 進行資料處理、統計分析與分群分析，並提供以下成果：

## 分析流程

1. NHANES 資料讀取與整理
2. 青少年研究樣本篩選
3. 飲食相關變項處理
4. 資料探索與描述性統計
5. 飲食型態分群分析
6. 分群結果整理與視覺化
7. 分析結果報告輸出
