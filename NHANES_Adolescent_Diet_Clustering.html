1 Introduction

Adolescence is an important stage of growth and development, during which adequate nutrition plays an essential role in maintaining health. Dietary habits established during this period may also influence health outcomes later in life.

The purpose of this study is to explore dietary habits among adolescents aged 12–18 years in the United States using data from the National Health and Nutrition Examination Survey (NHANES) 2021–2023.

Cluster analysis is applied to identify potential dietary patterns based on nutrient intake. By grouping individuals with similar nutritional characteristics, this study aims to describe distinct dietary profiles and explore differences in nutrient consumption across identified clusters.

2 Data Source and Study Population

2.1 Data Source

The data were obtained from the NHANES August 2021–August 2023 cycle.

The following datasets were used:

  • DR1TOT_L: Dietary Interview – Total Nutrient Intakes, First Day.
  • DEMO_L: Demographic Variables and Sample Weights.

The two datasets were merged using the participant identification number (SEQN).

Official data sources:

  • NHANES Dietary Data – DR1TOT_L
  • NHANES Demographic Data – DEMO_L

2.2 Study Population

Participants aged 12–18 years were included in the analysis.

Only participants with reliable Day 1 dietary recall information (DR1DRSTZ = 1) were retained.

The initial merged dataset contained 8,860 participants. After applying the age and dietary recall criteria, 670 adolescents remained.

One additional participant was excluded because of missing values in the selected nutrient variables.

Therefore, the final clustering analysis included 669 participants.

3.5 Data Standardization

Nutrient variables have different measurement units and scales. Directly applying Euclidean distance to the original variables may cause variables with larger numerical values to dominate the clustering results.

To address this issue, nutrient density was calculated as the amount of each nutrient consumed per 1,000 kcal.

Total energy intake was retained as an additional variable.

A logarithmic transformation using log1p() was applied to reduce right-skewness, followed by Z-score standardization.

energy <- analysis_dat$DR1TKCAL

# Exclude participants with non-positive energy intake
keep <- energy > 0

analysis_dat <- analysis_dat[keep, ]
energy <- analysis_dat$DR1TKCAL

density_vars <- setdiff(nutrient_vars, "DR1TKCAL")

# Nutrient intake per 1,000 kcal
x_density <- as.data.frame(
  lapply(
    density_vars,
    function(v) {
      analysis_dat[[v]] / energy * 1000
    }
  )
)

names(x_density) <- density_vars

# Combine log-transformed energy and nutrient density
x_main <- cbind(
  Energy_kcal = log1p(energy),
  as.data.frame(lapply(x_density, log1p))
)

# Z-score standardization
x_main <- as.data.frame(scale(x_main))

x_main <- as.matrix(x_main)

# Remove zero-variance variables if present
nonzero_sd <- apply(
  x_main,
  2,
  function(z) sd(z, na.rm = TRUE) > 0
)

x_main <- x_main[, nonzero_sd, drop = FALSE]

dim(x_main)

4 Clustering Methods

4.1 Elbow Method

The Elbow Method was used to examine the relationship between the number of clusters and the total within-cluster sum of squares (WSS).

As the number of clusters increases, WSS generally decreases. The optimal number of clusters may be suggested by the point where the reduction in WSS begins to slow down.

set.seed(2026)

k_candidates <- 2:8

wss <- sapply(
  k_candidates,
  function(k) {
    kmeans(
      x_main,
      centers = k,
      nstart = 30,
      iter.max = 100
    )$tot.withinss
  }
)

plot(
  k_candidates,
  wss,
  type = "b",
  pch = 19,
  xlab = "Number of clusters (k)",
  ylab = "Total within-cluster sum of squares",
  main = "Elbow Method"
)

4.2 Silhouette Statistic

The Silhouette Statistic evaluates how well each observation fits within its assigned cluster compared with other clusters.

A higher average silhouette width indicates better-defined clusters.

sil_width <- sapply(
  k_candidates,
  function(k) {

    km <- kmeans(
      x_main,
      centers = k,
      nstart = 30,
      iter.max = 100
    )

    sil <- silhouette(
      km$cluster,
      dist(x_main)
    )

    mean(sil[, "sil_width"])
  }
)

silhouette_results <- data.frame(

  average_silhouette = sil_width

4.3 Gap Statistic

The Gap Statistic compares the observed within-cluster dispersion with the expected dispersion under a reference distribution.

A larger Gap value suggests stronger clustering structure.

4.4 K-means Clustering

Based on the Silhouette Statistic, K = 2 was selected because it produced the highest average silhouette width among the evaluated solutions.

K-means clustering was then performed using 100 random initializations to improve the stability of the final solution.

selected_k <- k_candidates[
  which.max(sil_width)
]

set.seed(2026)

km_final <- kmeans(
  x_main,
  centers = selected_k,
  nstart = 100,
  iter.max = 200
)

analysis_dat$cluster <- factor(
  km_final$cluster
)

cat("Selected number of clusters:", selected_k)
## Selected number of clusters: 2

4.5 Hierarchical Clustering

Hierarchical clustering was also performed using Euclidean distance and complete linkage.

To make the dendrogram easier to display and reduce computational demands, a random sample of 500 participants was selected.

set.seed(2026)

hc_n <- min(
  nrow(x_main),
  500
)

hc_index <- sample(
  seq_len(nrow(x_main)),
  hc_n
)

hc_data <- x_main[
  hc_index,
  ,
  drop = FALSE
]

hc_dist <- dist(
  hc_data,
  method = "euclidean"
)

hc <- hclust(
  hc_dist,
  method = "complete"
)

5.2 Determination of the Number of Clusters

The Elbow Method showed a gradual decrease in within-cluster sum of squares as the number of clusters increased. However, no clearly defined elbow point was observed.

The Silhouette Statistic suggested that K = 2 was the best solution among the evaluated cluster numbers.

The Gap Statistic showed its highest value at K = 1 (1.0387), followed by K = 2 (0.9872).

This suggests that the dataset may not contain strongly separated natural clusters.

Despite this limitation, K = 2 was retained for exploratory interpretation because it provided the highest average silhouette width among the tested K-means solutions.

5.4.1 Cluster 1: Protein and Micronutrient-Rich Dietary Pattern

Cluster 1 included 363 participants (54.3%).

Compared with Cluster 2, this group showed:

  • Higher protein intake (86.10 g).
  • Higher total fat intake (87.79 g).
  • Higher cholesterol intake (349.77 mg).
  • Higher intake of several micronutrients, including vitamins A, B1, B2, B6, B12, and D.
  • Lower total sugar intake (96.36 g).
  • Higher plain water intake (1320.63 g).

This cluster can be described as a Protein and Micronutrient-Rich Dietary Pattern.

However, the relatively high fat and cholesterol intake suggests that this pattern should not automatically be considered healthier.

5.4.2 Cluster 2: Carbohydrate and Sugar-Heavy Dietary Pattern

Cluster 2 included 306 participants (45.7%).

Compared with Cluster 1, this group showed:

  • Higher carbohydrate intake (263.27 g).
  • Higher total sugar intake (119.50 g).
  • Lower protein intake (52.84 g).
  • Lower intake of several micronutrients.
  • Higher caffeine intake (35.53 mg).
  • Lower plain water intake (992.02 g).

This cluster can be described as a Carbohydrate and Sugar-Heavy Dietary Pattern.

The results indicate differences in nutrient composition between the two groups. However, the specific food sources responsible for these differences cannot be determined from total nutrient intake data alone.
